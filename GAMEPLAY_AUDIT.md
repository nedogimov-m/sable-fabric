# Sable: проверка игры и отображения, 25 октября 2026

Проверен настоящий графический Minecraft 26.3 с установленными production JAR: Create, Sable, Aeronautics Bundle и Fabric API. Veil и ImGuiMC загружаются из вложенных зависимостей Sable. Тестовый мод создаёт стенды, отправляет ввод и читает результаты; производственные классы и ресурсы не подменяются.

Окружение: Java 25, Fabric Loader 0.19.5, Fabric API 0.165.0+26.3, Apple M4/macOS, Vulkan через MoltenVK, без Sodium. Native launch сохраняет development-флаги Fabric из рабочего профиля; наличие DemoInspector не является доказательством обычного production launch без этих флагов.

## Исправления

**Падение инспектора участков.** Открытие `Sub-level Container` в пустом мире приводило к `IndexOutOfBoundsException` в `renderPlotContainer`: плотный список загруженных тел индексировался как полная двумерная сетка. Используется `getSubLevel(x, z)`, который корректно обрабатывает пустые ячейки и разреженное заполнение. Выбор ячейки ограничен наведением и границами сетки.

Окно получает начальный размер 640×360; обе сетки вписываются в доступную ширину и высоту. До настройки размера новый инспектор фактически занимал 32×39 пикселей. Проверены пустой мир, появление и удаление настоящего физического тела, узкое окно 340×500 и выход из редактора. Начальный размер проверяется через штатные ImGui window settings, изображение — чтением уже собранного GPU-кадра.

**Удаление из старого измерения отправлялось в новое.** После настоящего перехода Nether/Overworld сервер находил игрока через общий список и отправлял ему удаление участка старого мира. Пакет содержит относительный слот без измерения. На исходном прогоне с одинаковым слотом 0 в двух мирах тела сохранились, но каждый из четырёх переходов вызвал ошибку `tracking removal packet for unknown sub-level`. Потеря тела в этом прогоне не воспроизведена. Теперь отправка удаления ограничена игроками того же `ServerLevel`, включая удаление самого тела. Формат сети не менялся. Повторный прогон проверяет UUID в обоих мирах после четырёх переходов и отсутствие ошибочных удалений.

Ещё два подтверждённых дефекта общего интерфейса исправлены в ImGuiMC: переворот окна относительно мира в Vulkan и выход отрисовки за видимую область окна, частично находящегося за экраном. Подробности и исходные/исправленные пиксели: [отчёт ImGuiMC](https://github.com/nedogimov-m/imguimc-fabric/blob/26.3/GAMEPLAY_AUDIT.md).

## Повторение

Из корня Sable, с четырьмя **точными** production JAR и рабочими native launch arguments этого компьютера:

```sh
python3 scripts/run_gameplay_audit.py \
  --client-args /path/to/client.args \
  --mod ../26_3_porting/build/libs/create-fabric-6.0.10-port.2+mc26.3.jar \
  --mod build/libs/sable-fabric-26.3-2.0.6-port.1+mc26.3.jar \
  --mod ../Aeronautics/build/libs/aeronautics-bundle-fabric-26.3-1.3.2-port.1+mc26.3.jar \
  --mod /path/to/fabric-api-0.165.0+26.3.jar
```

По умолчанию выполняются восемь сценариев, строго по одному графическому клиенту. Повторяемый `--case` выбирает нужные сценарии. `restore` берёт сохранение успешного `physics`; для отдельного повторного запуска используется `--restore-from /path/to/physics/runtime.json`. Открывается копия мира. `--name` обязан быть новым, чтобы не перезаписать доказательства. Общий результат записывается в `build/gameplay-audit/<name>/summary.json`.

## Границы

Это проверка перечисленных действий на одном компьютере. Не проверены отдельная сессия с двумя игроками, физический геймпад, другие ОС/драйверы, Sodium, все сторонние интеграции и произвольные большие корабли. Успешный UTF-8 ввод не означает наличия каждого Unicode-глифа в настроенном шрифте. Свет/частицы/bloom имеют точные offscreen GPU-проверки в полном установленном мире; они не покрывают каждую возможную конфигурацию пользовательского эффекта. Предупреждения тестовой среды Minecraft, включая недопустимое исходное значение anisotropic filtering и отсутствующий `minecraft:end_of_frame`, не выдаются за исправления этих трёх модов.
